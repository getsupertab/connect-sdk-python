# Supertab Connect SDK

Python SDK for Supertab Connect.

## Usage

See the [Supertab Connect Docs](https://supertab-connect.mintlify.app/reference/sdk/python) for full SDK reference.

Check our scripts from the `examples` folder to get the idea of how to use the provided functionality.

## Development

This project uses `hatchling` as the build backend.

See [DEVELOPMENT.md](DEVELOPMENT.md) for local setup, Git hooks, and CI-aligned development commands.
